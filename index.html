来源与使用说明

本次内容

首批为 2010 年考研英语一 Text 4 的 32 张卡：28 张生词与短语，以及 4 张已讲过的对照词。保留原有词卡内容、原文形式、语境解释和释义出处。黄色标出目标词；红色波浪线对应已确认的答案线索。

词表与语境分开

词表原释义摘自所提供的《2027考研英语红宝书（乱序版）A4默写版》，标注编号及 PDF 页码；英文词表页码另列。“真题语境”是结合阅读整理的解释，不冒充词表原文。关联词条不代表整组短语被独立收录。本网站不提供完整 PDF 或整本词书。

词库更新，不清空进度

打开网站时读取最新发布的词库，也可点“检查更新”。新篇目加入选择栏，已有词卡保留稳定编号。更新不会重置自评；当前一轮保留原来的卡片列表，需要看新词时重新选择“本篇全部”。

手机与电脑：同一词库，进度各自保存

这是静态网站，没有账户和云端进度数据库。自评保存在当前浏览器；手机与电脑不会自动同步。清理浏览器数据或使用无痕模式可能丢失记录，请适时导出备份。本页不会上传个人学习记录。

迁移旧 HTML：在旧版词卡点“导出复习记录”，再在这里导入那个 JSON 文件。支持旧版 2010 Text 4 记录；导入按时间合并，不用较旧记录覆盖较新记录。网站和本地 HTML 属于不同存储位置，不会自动互通。

怎么用：先看英文 → 回想 → 翻开中文 → 认识 / 模糊 / 不认识。空格翻面，1 / 2 / 3 自评，方向键翻页。可关闭“显示真题提示”。朗读只使用设备提供的离线英语音色；没有音色也能正常背词。
